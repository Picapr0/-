# Как получить URL https://... для сайта

Репозиторий: https://github.com/Picapr0/-

---

## Способ A — Netlify (рекомендуется, бесплатный HTTPS)

### Шаг 1 — Загрузить код на GitHub

**Без Git на ПК:**

1. Откройте https://github.com/Picapr0/-
2. **Add file** → **Upload files**
3. Перетащите **всю папку** `telegram-prompt-app` (кроме `certs` и `config.local.json`)
4. **Commit changes**

**С Git:**

```powershell
cd "C:\Users\Пользователь\telegram-prompt-app"
.\push-to-github.ps1
```

### Шаг 2 — Netlify

1. https://app.netlify.com → **Add new site** → **Import an existing project**
2. **GitHub** → репозиторий **Picapr0/-**
3. **Environment variables** → `F5AI_API_KEY` = токен F5AI
4. **Deploy site**

### Ваш URL

```
https://ИМЯ-САЙТА.netlify.app
```

Укажите его в BotFather (`/newapp`).

---

## Способ B — Render (тоже https://)

1. https://dashboard.render.com → **New** → **Blueprint**
2. Подключите GitHub **Picapr0/-** (сначала загрузите код, см. шаг 1 выше)
3. Render прочитает `render.yaml`
4. Введите **F5AI_API_KEY** при запросе
5. URL: `https://ai-image-studio.onrender.com` (или похожий)

---

## Способ C — Только на компьютере

```
start-https.bat  →  https://localhost:8443
```

Для Telegram **не подходит**.
